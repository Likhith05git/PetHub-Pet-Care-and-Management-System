# PetHub - Pet Care and Management System

## 📌 Project Overview
PetHub is a Java-based web application designed to manage pet care services efficiently. 
It allows users to explore pet-related services, manage orders, and view pet care information.

## 🛠️ Technologies Used
- Java (Servlets & JSP)
- HTML, CSS
- Apache Tomcat Server
- MVC Architecture

## 📂 Project Structure
- src/main/java → Backend logic (Controller, Services)
- src/main/webapp → Frontend (JSP, HTML, CSS, Images)

## 🚀 Features
- Pet care service browsing
- Order management
- Informational pages (tips, blogs)
- Responsive UI

## ▶️ How to Run
1. Install Apache Tomcat
2. Import project into Eclipse/IDE
3. Deploy on Tomcat server
4. Run on browser (localhost:8080)
